# Tasks — azure-infra-as-code

Ordering follows design.md's Migration Plan: author + lint locally → preview against the live RG → adopt → prove OIDC unaffected → PAT → fresh-build rehearsal → converge the real VM → CI + docs. No task needs EDA tools or a long run; every gate is a local build/lint or a read-only Azure/GitHub query. Tasks marked **[Azure]** touch the live subscription; steps marked **(user)** are mutating `az`/`gh` commands the harness is expected to deny for agent execution (design D9) — the agent prepares the exact command and verifies the result read-only afterwards.

  **What failed the assertion:** the first pass logged `writing needrestart override /etc/needrestart/conf.d/99-ci-runner.conf`, i.e. it changed a file on the production runner host. The hand-written file differed from the script's canonical form; **what differed is now unknowable, because the write destroyed the evidence** — the script overwrites rather than diffing. The second pass reported it "is current", and the function is provably idempotent (verified locally: write-then-compare matches, 136 bytes, LF, trailing newline), so this was a one-time correction of pre-existing drift rather than a recurring rewrite. A `--check`/diff mode that reports the difference and exits non-zero without writing would have preserved the evidence here, and would make the "converge the existing VM" path safe to run exploratorily. Recorded as a follow-up rather than done now, since it is new scope beyond this change.
