# SHA-3 CV-X-IF coprocessor + MMIO comparison arm — tasks

Tags:

- **[edit]**: plain file editing.
- **[eda]**: a short tool run in the `newt-eda` image, taking minutes. This covers Verilator unit simulation, block-level yosys/OpenSTA, `pickle-all` and `bender`.
- **[xcelium]**: a run on the restricted Xcelium VM through `make ig-xrun-bundle` + `./run.sh`. A run takes minutes, but it involves a manual copy step.
- **[long-run]**: a full `synth-all` (~2.5–3 h, >35 GB RAM) or the P&R lane (hours, self-hosted VM). It runs only where the task says so, and never as a speculative check.
- **[manual]**: a GitHub repository-settings or fork-repository action.

Cheap gates (lint, unit sim, block synthesis, Xcelium tests) complete every task except the measurement tasks in groups 5 and 8.

Groups 1–5 are the ISE arm and stand on their own. Groups 6–8 are the MMIO comparison arm. If the schedule is cut, cut from group 6 onward.
