# Design

## Context

See proposal.md for why. State of things today:

- **The current SoC P&R section comes from two runs on the old flow.** `docs/results/sha3-ppa.md` § "SoC place and route" is generated by `scripts/sha3_ppa.py` (`--pnr/--pnr-ref` with `--pnr-run-id/--pnr-ref-run-id`) from two `pnr-reports` artifacts. Both runs used the taped-out die and the negotiation legalizer, and both placements had overlapping cells. The generator already detects overlaps (`pnr_cts_overlaps`, from `DPL-0005 Overlap check failed`) and prints a "Placement was not legal" paragraph. The flow description is a hard-coded string: "taped-out die, `gpl` pass 2 timing-driven repair virtual". So is the SoC-power paragraph, which quotes +14.6 % / +6.1 % from earlier runs.
- **Probe B (`38395368038`, `3fdacef`) is the both-arms side.**
  - `git diff 3fdacef a416399 -- hw target/ihp13 Bender.yml Bender.lock scripts/pnr` is 8 comment lines in `gpl.tcl`, so the synth key and the flow behaviour are the same as `main`.
  - Its `pnr-reports` have everything the requote needs:
    - `save/pnr_status.log`: every stage `ok` through `grt`, then `grt stop-after`;
    - `reports/pnr_floorplan.log`: `Die: 6777.0 x 5950.0 um (core scale 1.10 of the taped-out 6230.0 x 5478.0)`;
    - `reports/pnr_{dpl,cts}.log`: `Placement legal after <stage>`;
    - `reports/basilisk.grt.rpt`: uniform-activity power, 1.06 W, "comparative only".
  - The artifact expires 2026-11-12.
- **The old reference was a different tree.** `37108127061` ran `dff4df0`, which has the pre-coprocessor RTL: Cheshire fork `v0.3.1-newt.1`, no `Cva6CvxifEn`, no `AxiExt*` fields set, and `axi_ext_slv_req_o ( )` / `axi_ext_slv_rsp_i ( '0 )` in `iguana_soc.sv`. `main` is on `newt.2`, which adds the CV-X-IF port and the `Cva6CvxifEn` field (default 0).
- **The two lanes do not share synthesis.**
  - The synth lane (`synth.yml`) uploads `synth-reports`. It does **not** write the VM-local synth cache.
  - The P&R lane (`pnr.yml`) restores that cache by key or runs `synth-all` itself. It uploads only `pnr-reports` and the DEF.
  - All artifacts are kept 30 days.

## Goals / Non-Goals

**Goals:**

- A legal-placement reference on exactly the flow probe B ran, so the comparison changes only the SHA-3 hardware.
- Results docs whose figures, achieved period and energy all come from that pair, with the legality and die stated.

**Non-Goals:**

- A fresh both-arms run. Probe B is reused (user decision, 2026-10-14).
- Post-route repair or detailed routing on either side. The comparison stays at `grt`, labelled "before post-route repair", as the existing spec requires.
- Any flow tuning, the SPI-corner lever, or changes to the lane workflows on `main`.
- Re-measuring block synthesis, block power or cycle counts. Only figures derived from the SoC P&R run move.

## Decisions

### D1. Reference = `main` minus the SHA-3 hardware, on a throwaway branch

Branch `pnr-reference-no-arms` from `main` (`a416399` or later, as long as the flow diff from probe B stays comment-only), and on it:

- In `hw/iguana_pkg.sv` `gen_cheshire_cfg()`, drop `Cva6CvxifEn = 1` and the four `AxiExt*` lines. They fall back to Cheshire's defaults, CV-X-IF off and no external subordinate, as in the old reference.
- In `hw/iguana_soc.sv`, remove `i_keccak_cvxif` and `i_keccak_mmio`. Tie `cvxif_resp_i` to `'0`. Restore `axi_ext_slv_req_o ( )` / `axi_ext_slv_rsp_i ( '0 )`, which are size-0 arrays once `AxiExtNumSlv` is 0, as in `f4d43db`.
- In `target/ihp13/yosys/project-synth.mk`, remove the two `*/i_keccak_*` keep-hierarchy selectors. With no instance they would match nothing, which the spec treats as a defect.
- In `Bender.yml`, stop listing the four `hw/coproc/` sources and drop the direct `common_cells` dependency that only they needed. *Added 2026-10-15 after the first reference synth (run `38641205073`):* without this, the netlist matched `36447894410` in all 69 modules' parameter hashes and in every kept module, but not in the flattened top (−0.43 % cells, −0.10 % area). Synthesis is deterministic for identical input (two both-arms runs of the same RTL, `37218328058` and `38531460042`, are identical), so the delta came from the different pickled input, not the hardware. With this edit, `Bender.yml` equals `f4d43db`'s apart from the Cheshire pin, and `Bender.lock` is unchanged.

*Alternative rejected:* rebasing today's backend onto `dff4df0`/`f4d43db`. More files move: every `target/ihp13/openroad` change since 10-03. And showing that the flow is identical to probe B's is a large diff rather than a four-file one.

*Accepted difference:* Cheshire `newt.2` instead of `newt.1`. With CV-X-IF off, `newt.2`'s extra port is unused, and the synth check in D3 confirms the hardware is the same.

### D2. Synth lane first, then the P&R lane, both dispatched on the branch

1. `synth.yml` `workflow_dispatch` on `pnr-reference-no-arms` gives a `synth-reports` artifact for the D3 netlist check.
2. `pnr.yml` `workflow_dispatch` on the same branch with `stop_after=grt` and every other input empty, so the defaults equal probe B's.

The P&R lane will miss the synth cache and run `synth-all` again, because the synth lane does not fill that cache.

*Alternative rejected:* only the P&R lane, adding the yosys reports to its upload on the throwaway branch. It saves ~2 h (~$2.5) of VM time but edits a workflow, and the artifact would not have the `synth-reports` layout that `sha3_ppa.py --soc-ref` reads. Not worth it.

*Alternative rejected:* only the P&R lane and no netlist check. It loses the evidence that the reference is the same hardware.

Both runs are expensive. Each is dispatched only after the user approves it in the session.

### D3. Netlist identity check against `36447894410`

Compare the reference branch's synth metrics (cells, area, flip-flops, `CHECK`) with the pre-coprocessor run `36447894410`: 735,557 cells, 17,771,117 µm², 89,249 flip-flops. The pass band is the ±0.05 % the earlier reference showed against `synth-baseline.json`. Beyond it, stop and report to the user before running P&R. A larger delta means the branch is not the old reference hardware, for example CV-X-IF logic still elaborated in `cvxif_fu`.

If `36447894410`'s artifact has expired, use the figures recorded in `docs/results/sha3-ppa.md` § "SoC synthesis".

*Outcome (2026-10-15):* both reference syntheses came out −0.43 % cells, −0.10 % area and −0.02 % flip-flops against `36447894410`, outside the band. CVA6 is identical, and the delta sits in the flattened top and follows the Cheshire pin (`newt.2` against `newt.1`). The user decided to proceed and state the deviation instead of pinning `newt.1`, because the reference should match probe B's tree, which is on `newt.2`. The band is therefore advisory: a miss is reported with its location, not a stop.

### D4. Generator reads die and legality from the reports, and refuses mismatches

`scripts/sha3_ppa.py`:

- **Parse.** From `pnr_floorplan.log` take the `Die:` line (die size and core scale). From `pnr_dpl.log` / `pnr_cts.log` take `Placement legal after <stage>`. From `basilisk.grt.rpt` take uniform-activity total power, if present.
- **Fail on bad input.** Refuse to emit the P&R table when either run lacks a legality line for `dpl` or `cts`, when overlaps are found, or when the die lines differ. Print an error naming the run and the item. This replaces today's "Placement was not legal" paragraph, which can no longer be reached for a current comparison, and is what the spec requires.
- **Generate the flow sentence from what was parsed.** It gives the die size and scale, the diamond legalizer, legal placement after `dpl` and `cts`, and `stop_after=grt`. It replaces "taped-out die, `gpl` pass 2 timing-driven repair virtual".
- **Generate the power paragraph from the two runs.** Report reference and both-arms totals under uniform activity, and their delta, labelled comparative only and not workload power. Keep one sentence saying default activity does not converge (Phase 17). The hard-coded +14.6 % / +6.1 % go, because they come from other runs. The coprocessor-only figure has no run on the current flow and is dropped.
- **Clock / non-clock power split** *(added 2026-10-16, user decision)*. With both sides on one fixed die, the smaller reference is placed more sparsely and CTS builds it a larger clock tree. In the first pair, the reference had 0.611 W of clock power against 0.397 W, so its total was 15 % *above* the SoC with the arms. The paragraph therefore reports the total, the clock network, and everything else (summed from the groups, which carry three significant figures each), plus the CTS clock-buffer counts. Only the non-clock delta is attributed to the arms.
- **State-dependent sentences.** "WNS barely moves against the reference" and "congestion fell although the netlist grew" are emitted only when the new figures support them. WNS within 0.5 ns, and demand lower with arms, respectively. Otherwise neutral wording.

Old artifacts lack these lines, so the generator can no longer regenerate the 37108127061/37162759719 pair. That is intended. Those figures survive as the superseded record in `sha3-evaluation.md` (D5).

### D5. Superseded figures live in the hand-written summary only

`docs/results/sha3-ppa.md` is generated and shows only the current pair. `docs/results/sha3-evaluation.md` gets:

- the new timing row and the new achieved period;
- energy prose updated to match;
- a short dated "Superseded" note with the old pair, why it was replaced (overlapping cells, taped-out die, old flow), and the before→after WNS and period.

That keeps the methodological point, how much legality and the flow fixes moved the result, without letting old figures feed any derived number.

### D6. Keep local copies of the four artifacts

Before any run expires, download probe B's `pnr-reports` and the new reference's `synth-reports` and `pnr-reports` to `target/ihp13/openroad/out/ci-<run>/` and `target/ihp13/yosys/out/ci-<run>/`. Both are gitignored (`target/ihp13/*/out/`). The results docs name the run IDs. The copies only let the docs be regenerated after the 30-day retention.

## Risks / Trade-offs

- **[The reference P&R fails a gated stage.]** The reference is smaller (~845 k vs ~976 k cells) on the same 1.10 die, so its utilization is lower and legalization should be easier. → If it fails anyway, report the stage and log to the user. Do not quote a partial run. The spec's "unavailable stage" scenario applies.
- **[Netlist check fails (D3).]** → Stop before P&R and investigate the branch. Do not widen the band.
- **[Probe B was one run on a branch, not `main`.]** → D1 checks that the flow diff is comment-only. Run-to-run placement variance is already a stated caveat ("one run each").
- **[The achieved period moves, so every energy-at-period figure moves.]** It goes from 19.23 to about 19.96 ns if probe B's −8.96 ns WNS stands. → Only the leakage share scales with the period (< 0.2 % per the current text). The regenerated tables and the summary prose are updated together in one PR.
- **[Comparison against the previous reference becomes impossible to regenerate.]** → Intended (D4). The old figures stay quoted, labelled as superseded.
- **[VM queue contention with the nightly synth cron.]** Both lanes share one runner and queue rather than cancel. → Dispatch outside 02:30 UTC, or accept the queue.
